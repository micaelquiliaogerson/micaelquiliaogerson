### Engenheiro de Software | Entusiasta de Arquitetura

Atualmente, foco meu trabalho no desenvolvimento de aplicações modernas com **Node.js (Express)** e **React (Next.js)**, além de construir ecossistemas de automação robustos utilizando **RPA (UiPath)** e **Python**. 

Sempre fui movido pela entrega de soluções que funcionam, mas hoje meu foco está em **como** elas são construídas.

### 🧠 Filosofia de Engenharia

Acredito que, em um mundo onde a Inteligência Artificial acelera a escrita de código, o verdadeiro diferencial do engenheiro está no **domínio dos fundamentos** e na **tomada de decisão arquitetural**. 

Minha busca atual é pela excelência técnica:
- 🏗️ **Padrões de Projeto & Clean Code**: Escrever código que humanos entendam e que o tempo não destrua.
- 🏛️ **Arquitetura de Sistemas**: Estudo constante de desacoplamento, responsabilidade única e integração entre camadas (Java Core + Node Gateway).
- 🤖 **IA como Aliada, não Muleta**: Acompanho e utilizo o avanço das IAs para produtividade, mas prezo pelo conhecimento profundo para saber exatamente o que está sendo executado "sob o capô".
